Ứng dụng C# / WPF đọc phổ gamma Canberra CNF trên Windows 10/11 x64.

**Tải:** `GammaCNFReader-CSharp-Setup.exe` để cài đặt; hoặc giải nén `GammaCNFReader-CSharp-Windows-x64.zip` và chạy `GammaCNFReader.exe`. Không cần Python hoặc cài .NET riêng.

Hỗ trợ mở/kéo thả CNF, phổ theo kênh/keV, zoom, thang log, thời gian đo, xuất CSV/PNG. Chưa nhận diện đồng vị hoặc tính hoạt độ.

**Trạng thái:** bản thử nghiệm (prerelease), chưa ký số. Đã đạt 18 kiểm tra dữ liệu với một file mẫu riêng tại môi trường phát triển; CI chạy 11 kiểm tra chung vì không đưa file mẫu người dùng vào repository. Chưa kiểm chứng thao tác giao diện và cài/gỡ trực tiếp trên PC Windows; chưa đối chiếu với Genie 2000. Vui lòng kiểm tra với file của bạn trước khi dùng cho công việc chính thức.
